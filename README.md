# Крипто Дашборд

Веб-страница, которая показывает курсы криптовалют в реальном времени.

[Открыть дашборд](https://bobervlad11-svg.github.io/crypto-dashboard/)

## Что умеет

- Показывает текущие цены Bitcoin, Ethereum и Solana
- Показывает изменение цены за 24 часа: зелёным при росте, красным при падении
- Автоматически обновляет данные каждую минуту
- Корректно обрабатывает ошибки API

## Технологии

- HTML, CSS, JavaScript
- [CoinGecko API](https://www.coingecko.com/en/api) — источник данных о ценах
